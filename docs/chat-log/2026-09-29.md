# 引継ぎメモ（2026-09-29）

このチャットが消えても続きから再開できるように、当日の合意・作業・未着手を残す。

## プロジェクトの目的

- 國學院駅伝部を家族で応援するための情報サイト。
- 非公式の家族向けアーカイブ。公式サイトの代替ではない。
- Cursor の AI チャットから、その時点のウェブ上の最新情報を集めて記事にしていく運用を想定。

## 技術方針（合意済み）

- 公開は **Cloudflare Pages**、リポジトリは **GitHub**。
- **サーバサイドプログラムは使わない。** HTML / CSS / JS と画像・動画の静的サイト。
- **プロジェクトルートをサイトのルートにする。**
- Cloudflare と Git の準備は、手順を AI が書いたあと **人間が行う**。デザイン決定前には着手していない。
- 本番の記事は Cursor チャットで収集・執筆し、静的ファイルとして追加していく。

## サイトの構成要素（予定メニュー）

1. **News**  
   ウェブから探した國學院駅伝部の最新ニュース。
2. **Datas**  
   人間がテーマを指示し、ウェブからデータを集め、指定した表示でテーマごとにまとめる。  
   例:
   - 出雲駅伝2026の予想エントリーと、そのランナーの予想タイムを表で表示
   - 歴代國學院ベスト10（5000m / 10000m / ハーフなどの公式記録を集めてリスト化）
3. **Images**  
   ウェブから集めた写真・動画。

現状、メニューはこの3つが基本。

### 見た目の参照

- スクールカラーは國學院大學の **赤紫（あかむらさき）**。校旗の金もアクセントに使用。
- サンプル上の色の目安: `#b0175a` 前後。公式の DIC 193p / CMYK C35 M100 Y12 を参考にした解釈であり、ブランドガイドラインの厳密な再現ではない。
- こくぴょん等の公式キャラクターは使用していない（利用申請が必要なため）。
